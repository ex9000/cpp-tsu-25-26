### 📌 Описание программы		
Программа читает данные из файла data.kpst (пока тот же txt), обновляет или добавляет записи на основе ввода из стандартного потока (stdin), а затем сохраняет обновлённые данные обратно в файл.	
Каждая запись состоит из уровня, ключа и целочисленного значения.	


---
---

### 📂 Формат файла data.kpst	
Каждая строка имеет следующий формат:		
<дефисы><ключ> <значение>

Где:	

<дефисы> — ноль или больше символов -, определяющих уровень записи	

<ключ> — строка без пробелов	

<значение> — целое число

```bush
Примеры:
kapusta 10
-chinese 6
--nolegal 5
--legal 1
-belarussian 4
```

---
---

### ⌨️ Формат ввода (stdin)	
Программа принимает данные из стандартного ввода в следующем формате:	
<дефисы><ключ> <значение>	

Пример ввода:	
```bush
-- peaple 10	
banana 10
- nobanana 1
```
